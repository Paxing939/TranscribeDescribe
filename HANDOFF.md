## 1. Что хочет пользователь

- Фоновый сервис под **Windows** (позже, возможно, **Ubuntu**), который:
  - замечает начало звонка: по появлению чужих голосов или по открытию звонка. Часть звонков идёт **в браузере**;
  - пишет **звук и видео** на время звонка;
  - либо предлагает записывать каждый звонок: OBS всегда в трее, небольшой оверлей запускает запись через OBS, а в конце предлагает её остановить и **предлагает название для видеофайла**;
  - **после звонка** расшифровывает запись локальной моделью распознавания речи и делает **саммари через LLM**.
- Готовое решение тоже подойдёт: желательно бесплатное и локальное, в идеале open source.
- Звонки в основном на русском.
- Последнее пожелание по стеку: **компилируемый язык** с нормальными фреймворками для локальных LLM и распознавания речи. Рассматривались Rust, Go, C#, C++.

## 2. Что обсудили и к чему пришли

1. **Готовые решения.**
   - OBS + Advanced Scene Switcher — автозапись видео по процессу, без расшифровки.
   - Meetily, Hyprnote — только звук; Hyprnote слаб на Windows.
   - Screenpipe — пишет всё подряд 24/7.
   - Vibe / Buzz — расшифровка готовых файлов.
2. **Детект звонка на Windows.**
   - Реестр `HKCU\Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\microphone`: `LastUsedTimeStop == 0` означает, что микрофон занят прямо сейчас.
   - Браузер виден как `chrome.exe` / `msedge.exe`, но без вкладки, поэтому вкладку уточняем по заголовкам окон.
   - Конец звонка: микрофон освобождён или долго тихо на обеих дорожках → вопрос «Звонок закончился?».
3. **ТЗ v1** (`callscribe-spec.md`).
   - Стек: Python 3.12 + PySide6 + OBS (obs-websocket v5) + faster-whisper + LLM (Ollama / OpenAI-совместимый / Anthropic).
   - OBS пишет 3 аудиодорожки: микс / микрофон / системный звук. Отсюда разделение «Я / Собеседник» без диаризации.
   - Расшифровка и саммари — после звонка, в отдельном worker-процессе.
4. **PyInstaller.** Для себя не нужен: хватит `uv` + `[project.gui-scripts]`. Нужен только для раздачи: сборка one-folder, с CUDA весит гигабайты.
5. **Компилируемые языки.** Во всех четырёх модели работают на одних и тех же C/C++-движках (whisper.cpp / llama.cpp на ggml, ONNX Runtime / sherpa-onnx). Выбор определяют биндинги, UI (трей и оверлеи) и сборка под Windows.
   - **Rust + Tauri 2 — основной кандидат.** На нём сделаны Meetily, Hyprnote, Vibe. Библиотеки: whisper-rs, llama-cpp-2 / mistral.rs, sherpa-rs, obws. Трей, хоткеи, автозапуск, single instance, установщики и `content_protected` есть из коробки или плагинами.
   - **C#** — близкий второй: Whisper.net, LLamaSharp, sherpa-onnx, obs-websocket-dotnet. UI на Avalonia, а не WPF, если нужна Ubuntu.
   - **C++ + Qt** — только если C++ основной язык.
   - **Go** — не подходит: нет встраиваемого LLM, слабый GUI, cgo + CUDA на Windows.
   - Советы: собирать whisper.cpp и llama.cpp с Vulkan-бэкендом вместо CUDA; в MVP держать LLM в Ollama по HTTP.
6. **OpenWhispr** (github.com/OpenWhispr/openwhispr; MIT; Electron + React + TypeScript; v1.10.2 от 15.09.2026). Проверен по README, CLAUDE.md, CHANGELOG и коду детекта (подробности в §4). Вывод: **аудио-часть требований закрывает почти целиком, видео и OBS нет**.
7. **Обзор других репозиториев** (09.10.2026; проверено по коду и GitHub API). Готового решения под все требования нет: любой форк — это 3–5 крупных доработок.
   - **pasrom/meeting-transcriber** — только macOS (Swift, CoreML). Идеи перенесены в ТЗ: детект по окнам, режим «только запись», протокол саммари.
   - **Meetily** — open-core: в бесплатной версии нет детекта, видео нет, микрофон и системный звук сведены в один поток; аналитика PostHog.
   - **Anarlog** (бывший Hyprnote; Rust/Tauri, MIT + закрытая папка `enterprise/`):
     - сильный детект на Windows, раздельные каналы, DeepSeek есть;
     - но на Windows нет локальной расшифровки — модели включены только на Apple Silicon;
     - ~390 тыс. строк Rust + ~320 тыс. TS, ~480 коммитов в месяц; аналитика включена по умолчанию, в коде проверки «Pro».
   - **Prismical** (MIT; Electron + C#) — локальный конвейер на Windows (whisper.cpp, русский, OpenAI-совместимый LLM). Но нет автостопа, видео и локальной диаризации; проекту с апреля 2026, 2 автора.
   - **AutoDoc** (AGPL; Electron) — пишет экран и раздельные дорожки, детект на Windows. Но язык зашит `en`, LLM только Ollama, Telegram нет.
   - **OBS + Advanced Scene Switcher** — вариант без своего приложения:
     - условия по процессу и заголовку окна; по микрофону — через свой скрипт;
     - окно-вопрос для выбора режима, сцена на каждый монитор, профиль «только звук»;
     - после стопа запускает скрипт и передаёт ему путь к файлу.
   - **Cap** (AGPL, Rust/Tauri) — лучшая запись экрана на Windows, но огромный, без режима «только звук» и детекта; можно вызывать его CLI.
   - **Отпали:** Screenpipe (с июня 2026 коммерческая лицензия), Glass (удалён), Minutes / StenoAI / Note67 (детект только на macOS), obs-localvocal (только в реальном времени, модель на каждую дорожку).
   - **Блоки для своего приложения на Rust:**
     - детект — `meeting-detect` из Vibe и `detect` из Anarlog (MIT);
     - расшифровка — `transcribe.cpp` / `transcribe-rs` (MIT; Whisper, Parakeet, GigaAM v3) или sherpa-onnx (Apache-2.0);
     - звук — крейт `wasapi`; экран — `windows-capture` или ffmpeg `ddagrab` + NVENC; LLM — `async-openai`;
     - образцы кода: MeetRec (MIT), Vuoom (Apache-2.0). CallAudioRecorder (C#, русский через GigaAM v3) — без лицензии, только читать.
8. **OpenWhispr уточнено.**
   - Есть саммари встреч: AI Summary, подробные заметки, follow-up письмо.
   - Провайдер `custom` принимает любой OpenAI-совместимый адрес — DeepSeek подключится.
   - Локальные модели и свои ключи бесплатны и без лимитов (§4).
   - Видео в пути B — через OBS (obs-websocket-js) или встроенный в Electron захват экрана.

## 4. OpenWhispr: что есть, что проверить, где смотреть

**Есть:**

- **Детект встречи.**
  - Монитор микрофона с PID процесса.
  - Список процессов, которые живут только во время встречи. Windows: `cpthost.exe` (Zoom), `ms-teams_modulehost.exe` (Teams), `webexmeetingsapp.exe` (Webex). Linux: `zoom`, `teams`.
  - Календари.
  - Только промпт, **автозаписи нет**. Браузерные звонки и Telegram ловятся как общая «встреча» без имени приложения.
- **Захват звука** двумя потоками: микрофон и системный звук. Есть защита от эха собеседника в микрофоне.
- **Автостоп.** Запись останавливается по окончании звонка, 30 с можно продолжить. Забытая запись завершается после отсчёта 60 с.
- **Расшифровка** локально: whisper.cpp или Parakeet v3 (sherpa-onnx). **Русский поддерживают оба.**
- **Диаризация** с отпечатками голосов.
- **Саммари:** AI Summary, подробные заметки, follow-up письмо. LLM локальная через `llama-server` (GGUF) или по своему ключу.
- **Хранение:** заметки в SQLite с FTS5, семантический поиск через Qdrant. Экспорт транскрипта встречи в Markdown с таймкодами.
- **Видео** можно только загрузить готовым файлом для расшифровки.
- **Платформы:** Windows, Linux (AppImage / deb / rpm), macOS. Есть русская локализация интерфейса.

**Проверить:**

- ~~Лимиты бесплатного плана~~ — проверено 09.10.2026 по прайсу и коду: лимиты (5 ч встреч в месяц, 2000 слов в неделю) касаются только OpenWhispr Cloud — в коде лимит приходит только ответом 429 от их сервера. Локальные модели и свои API-ключи — без ограничений; speaker labels есть во всех планах. Платные только интеграции (MCP, CLI, коннекторы).
- Детект в настройках по умолчанию выключен (`processDetection`, `audioDetection` = false).

**Полезные файлы** (как образец для своего приложения или точки входа для форка):

- `src/helpers/meetingDetectionEngine.js` — объединение сигналов (процессы, микрофон, календарь), промпты, автостоп (`meetingAutoEndController`).
- `src/helpers/meetingProcessDetector.js` — список процессов встреч.
- `src/helpers/audioActivityDetector.js` и `resources/windows-mic-listener.c`:
  - Windows — WASAPI session monitor с событиями `MIC_START <pid>` / `MIC_STOP <pid>`;
  - Linux — `pactl subscribe` + `pactl --format=json list source-outputs` (`application.process.id`).
- `resources/windows-system-audio-helper.c` — WASAPI process loopback без собственного дерева процессов (Windows 10 2004+); фолбэк — Chromium display-media loopback.
- `src/helpers/meetingEchoLeakDetector.js`, `meetingMicGate.js`, `meetingMicHoldback.js` — борьба с эхом собеседника в микрофоне.
- `src/helpers/onnxWorkerClient.js` → `src/workers/onnxWorker.js` — ONNX-инференс в отдельном процессе: нативный краш не роняет приложение.
- `src/config/languageRegistry.json` — поддержка языков по движкам (`ru`: whisper ✓, parakeet ✓).
- `scripts/download-llama-server.js`, `src/services/ai/inferenceProviders/` — локальная и облачные LLM.
- `src/helpers/database.js` — SQLite.
